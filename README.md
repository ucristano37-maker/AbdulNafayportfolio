# Abdul Nafay — Portfolio Website

## What's inside
- `index.html` — main page (Home, About, Skills, Projects, Certificates, Education, Hire Me, Social, Contact)
- `css/styles.css` — all styling (dark premium theme, animations, responsive layout)
- `js/skills.js` — your skills list + percentages (edit this to add/change skills)
- `js/projects.js` — your projects list (4 real GitHub repos + concept placeholders)
- `js/certificates.js` — your 13 certificates (title, organization, date, description, image)
- `js/main.js` — all interactivity (preloader, typewriter, modals, contact form, animations)
- `assets/certs/` — your 13 certificate images (auto-converted from your uploaded PDFs)

## Still needs your input

  If you want a phone/WhatsApp number shown, open `index.html`, find the `id="hire"` section,
  and add a line like:
  `<a class="btn" href="tel:+92XXXXXXXXXX">Call →</a>`

## How to deploy to GitHub Pages
1. Delete the old contents of your `Portfolio-` repo (or create a fresh repo).
2. Upload/commit everything in this zip (keep the folder structure exactly as is).
3. In the repo → Settings → Pages → set source to the `main` branch, root folder.
4. Wait 1–2 minutes, then visit `https://ucristano37-maker.github.io/Portfolio-/`.
